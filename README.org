* gptel-autosave

Automatically save a conversation after receiving a response in gptel

* Installation

(use-package gptel-autosave
  :after gptel
  :vc (:url "https://github.com/grolongo/gptel-autosave")
  :hook (gptel-mode . gptel-autosave-mode))

* Available customization

| User Option                | Default                             | Description                                            |
|----------------------------+-------------------------------------+--------------------------------------------------------|
| gptel-autosave-directory   | ~/.config/emacs/gptel-conversations | Directory where transcripts of conversations are saved |
| gptel-autosave-slug-length | 6                                   | Maximum number of words for a filename                 |
| gptel-autosave-stopwords   | NLTK English stopwords corpus       | List of pronouns, articles, verbs, etc to trim out     |
