#+TITLE: gptel-autosave

This package will automatically save whole conversation into a file as a
transcript after each response received inside a gptel buffer.

For example, if you start a conversation with the prompt “What is the difference
between a function and a variable in Elisp?”, the conversation will be
automatically saved in the file difference-between-function-variable-elisp.org
(or .txt/.md).

** Installation

#+BEGIN_SRC emacs-lisp
(use-package gptel-autosave
  :after gptel
  :vc (:url "https://github.com/grolongo/gptel-autosave")
  :hook (gptel-mode . gptel-autosave-mode))
#+END_SRC

** Available customization

| Variable                   | Default                             | Description                                            |
|----------------------------+-------------------------------------+--------------------------------------------------------|
| gptel-autosave-directory   | ~/.config/emacs/gptel-conversations | Directory where transcripts of conversations are saved |
| gptel-autosave-slug-length | 6                                   | Maximum number of words for a filename                 |
| gptel-autosave-stopwords   | NLTK English stopwords corpus       | List of pronouns, articles, verbs, etc to trim out     |
